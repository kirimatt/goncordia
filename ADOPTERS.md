# Who uses goncordia

yourself: it tells new users which setups are proven, and it helps the
project.

To be listed, open a pull request that adds a row below, or fill in the
[adopter issue form](https://github.com/kirimatt/goncordia/issues/new?template=adopter.yml)
and a maintainer will add it for you.
